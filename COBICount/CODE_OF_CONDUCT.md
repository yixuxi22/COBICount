# Code of conduct

Project participants must communicate professionally and respectfully. Harassment, discrimination, personal attacks, doxxing, or publication of private data are not tolerated.

Technical disagreement is welcome when it is evidence-based and directed at code, experiments, documentation, or protocol design rather than individuals. Maintainers may edit, hide, or remove content and restrict participation when necessary to protect the project community.

Report conduct concerns privately to the repository maintainers after the public repository is created.
